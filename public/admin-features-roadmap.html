⚡ NoCode DAP Extended • Admin Console Strategic Roadmap

NoCode DAP Admin Console 추가 권장 메뉴 및 고도화 명세서

글로벌 상용 DAP(WalkMe, Whatfix, Pendo)의 운영 관행을 벤치마킹하여, 관리자의 관제력과 실무 편의성을 극대화하기 위해 추천하는 6대 핵심 메뉴, 화면 구성 및 단계별 구축 로드맵입니다.

📌 대상 시스템: nocodedapEx (포트 3050) 🏛️ 문서 구분: 기능 명세 & 아키텍처 로드맵 📅 작성 일시: 2026년 10월 2일 🔗 현재 관리자 포털: /admin 바로가기
🚀

1. 발행 & 라이프사이클

초안(Draft)과 발행(Published) 분리, 1-Click 긴급 숨김 스위치, JSON 백업/복원(Import/Export).

📊

2. 퍼널 & 행동 분석

스텝별 완료율 및 이탈률(Drop-off Funnel) 차트, 가이드 센터 미해결 검색어 분석.

👥

3. 사용자 세그먼트

신규 입사자/관리자 등 역할(Role)별 노출, 방문 횟수/기간/디바이스 조건부 트리거 빌더.

🎯

4. 비콘 & 핫스팟

긴 투어 없이도 버튼 옆에 깜빡이는 파란 불빛(Pulse Beacon)을 찍어 1초 만에 안내하는 경량 가이드.

Detailed Specifications

📦 1. 가이드 라이프사이클 & 발행 통제 (Publishing & Lifecycle)

관리자가 작성 중인 미완성 가이드가 일반 사용자에게 바로 보이는 사고를 방지하고, 특정 가이드를 안전하게 검토 후 라이브로 승격합니다.

🚀

초안(Draft) vs 발행(Published) 워크플로우

안전한 검토 단계 확보

저작기에서 저장 시 'Draft'로 생성되며, 관리자가 콘솔에서 [발행] 버튼을 눌러야 런타임에 노출됩니다.

  • Draft 상태: 관리자/저작자에게만 보이고 일반 유저에겐 숨김
  • Review 모드: 실제 화면에서 시연 링크(`?dap_preview=...`)로 사전 검증
  • Publish 즉시 반영: 런타임 캐시를 즉시 갱신하여 라이브 배포
🔘

1-Click 긴급 활성/비활성화 스위치

운영 즉각 대응 스위치

웹 애플리케이션 코드를 재배포하지 않고도 가이드별 On/Off 토글 스위치로 노출을 즉시 제어합니다.

  • 사이트 UI 개편 또는 긴급 점검 시 가이드를 삭제하지 않고 일시 숨김
  • 마스터 테이블 행마다 직관적인 토글 스위치 제공
  • 비활성화 시 API 조회 시 필터링되어 네트워크 트래픽 절약
💾

가이드 백업 & 복원 GUI (Import/Export)

재해 복구 및 스테이징-운영 이관

콘솔 툴바에 [JSON 백업 다운로드] 및 [백업 파일 불러오기] 모달을 배치합니다.

  • 스테이징(Staging) 환경에서 만든 가이드를 운영(Prod)으로 원클릭 이관
  • 전체 가이드 또는 특정 App ID 단위 선택적 백업 지원
  • JSON 파일 드래그 앤 드롭 유효성 검사 후 데이터베이스 트랜잭션 적재

📉

스텝별 이탈율 (Drop-off Rate) 진단

가이드 품질 측정 지표

팝오버마다 [다음], [이전], [닫기(X)] 이벤트 로그를 백엔드에 집계하여 퍼널 그래프로 시각화합니다.

  • 가장 이탈이 많은 '병목 스텝'을 붉은색 경고 배지로 표시
  • 평균 가이드 소요 시간(초) 및 완주율(%) KPI 제공
🔍

가이드 센터 미해결 검색어 분석

새 가이드 발굴 인사이트

사용자가 가이드 센터 검색창에 입력했으나 검색 결과가 0건이었던 키워드를 순위별로 수집합니다.

  • 예: "세금계산서 발행"(24회 검색, 미등록) -> 즉시 새 가이드 제작 필요성 발견
  • [이 검색어로 새 가이드 만들기] 버튼 연계

👥 3. 세그먼트 & 조건부 규칙 빌더 (Targeting & Audience)

신입사원에게는 상세 온보딩을, 숙련자에게는 신규 기능만, 관리자에게는 관리 메뉴 가이드만 맞춤으로 분기합니다.

🎭

사용자 역할(Role) 기반 노출

권한별 가이드 분리

웹 애플리케이션의 사용자 권한 변수(예: `window.DAP_USER_ROLE = 'admin'`)에 따라 노출할 가이드를 필터링합니다.

  • 권한 태그 다중 선택: `[관리자]`, `[영업팀]`, `[신입사원]`, `[전체]`
  • 일반 사원 화면에는 불필요한 관리자 가이드가 노출되지 않음
⏱️

조건부 트리거 규칙 (Trigger Rules)

노출 시점 및 빈도 제어

URL뿐만 아니라 사용자의 상태와 환경에 따라 가이드를 실행할지 결정하는 규칙 엔진을 탑재합니다.

  • 첫 방문자 전용: 해당 URL에 처음 들어왔을 때만 1회 자동 팝업
  • 기간 지정 노출: 특정 이벤트 기간(예: 10/1 ~ 10/15) 동안만 노출
  • 디바이스 필터: 데스크톱 전용 가이드 vs 모바일 전용 가이드

🎯 4. 핫스팟/비콘(Beacon) & 공지 배너 관리

긴 스텝의 투어 외에도, 새 버튼 옆에 깜빡이는 작은 파란 점(Beacon)을 찍어 1초 만에 주의를 끄는 마이크로 가이드를 제공합니다.

📍

펄스 비콘(Pulse Beacon / Badge) 관리

1초 경량 핫스팟 가이드

새로 개편된 메뉴나 버튼 모서리에 펄스 애니메이션 배지(`●`)를 띄우고 호버 시 1줄 툴팁을 보여줍니다.

  • 사용자가 한 번 확인(클릭)하면 자동으로 사라지는 배지
  • 화면 디자인을 해치지 않고 신기능을 강조하는 가장 효과적인 수단
📢

인라인 공지 배너 (Top Announcement Bar)

전사 긴급 공지 바

개발 배포 없이 Admin에서 웹사이트 최상단에 공지 띠 배너를 띄우고 내릴 수 있습니다.

  • "오늘 오후 7시 정기 점검 안내" 등의 공지를 원클릭으로 송출
  • 배너 닫기 버튼 및 다시 보지 않기(쿠키/localStorage) 연동

⚙️ 5. 시스템(App ID) 관리 & 테마 브랜딩 (Theme & Settings)

회사의 기업 CI(로고, 기본 컬러, 폰트)에 맞춰 가이드 팝오버의 스타일을 Admin에서 직접 커스터마이징합니다.

🏢

다중 시스템(App ID) 동적 등록 & 도메인 관리

멀티 테넌트 관리

ERP, 그룹웨어, 고객센터 등 신규 연동 앱을 관리자 화면에서 직접 등록하고 허용 도메인(CORS)을 지정합니다.

  • 시스템별 고유 식별자(App ID), 표시 이름, 관리자 배정
  • 안전한 호출을 위한 허용 출처(Allowed Origins) 화이트리스트 관리
🎨

브랜드 테마 스타일러 (Theme Styler)

회사 맞춤형 디자인

Driver.js 팝오버의 메인 테마 색상, 버튼 스타일, 모서리 둥글기(Border Radius), 로고를 CSS 코딩 없이 선택합니다.

  • 회사 CI 메인 컬러 피커 (Primary Color Picker)
  • 가이드 센터 버튼 텍스트 및 아이콘 선택 ("도움말", "가이드", "?")
🗺️ 3단계 구현 로드맵 (Phased Implementation Roadmap)
Strategic Timeline

운영 안정성에 직결되는 기능부터 순차적으로 적용하여, 최소 공수로 최대의 엔터프라이즈 거버넌스 효과를 얻을 수 있도록 단계를 구성했습니다.

Phase 1: 운영 필수 (안정성 & 통제력 확보)
1단계: 가이드 발행 상태 분리 & 원클릭 백업/복원
미완성 가이드 노출을 방지하기 위한 초안(Draft)/발행(Published) 워크플로우를 신설하고, 마스터 테이블에 긴급 On/Off 토글과 JSON Import/Export GUI를 탑재합니다.
✓ 초안/발행 상태 DB 필드 추가 ✓ 테이블 행별 On/Off 실시간 토글 ✓ 1-Click JSON 내보내기/가져오기 UI ⏱️ 예상 공수: 1 ~ 2주
Phase 2: 데이터 기반 운영 (사용자 분석 & 품질 측정)
2단계: 스텝별 완주/이탈 퍼널 차트 & 미해결 검색어 분석
가이드 실행 시 스텝 이동 및 이탈 이벤트를 수집하여, 스텝별 완료율 퍼널(Funnel) 그래프를 콘솔에 시각화하고 가이드 센터 미해결 검색 쿼리 순위를 수집합니다.
✓ 런타임 이벤트 로깅 API (`/api/analytics/events`) ✓ 이탈율 퍼널 차트 (Chart.js / CSS Funnel) ✓ 검색어 인사이트 TOP 10 ⏱️ 예상 공수: 2 ~ 3주
Phase 3: 엔터프라이즈 확장 (개인화 & 안내 형태 다양화)
3단계: 역할별 타깃팅, 핫스팟 비콘, 브랜드 테마 스타일러
사용자 권한(Role) 및 방문 횟수 기반 조건부 트리거 빌더를 구축하고, 펄스 비콘(Beacon) 마이크로 가이드와 테마 스타일러를 연동합니다.
✓ 사용자 역할(Role) & 세그먼트 매핑 ✓ 펄스 비콘(Beacon) 핫스팟 저작/실행 ✓ 브랜드 컬러 & 테마 스타일러 ⏱️ 예상 공수: 3 ~ 4주
