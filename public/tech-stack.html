1. 시스템 전체 아키텍처 (4-Tier Standalone Architecture)

외부 클라우드나 무거운 RDBMS 서버 없이 100% 로컬 및 사내 인트라넷에서 자립 구동되는 4계층 분리 구조

👑 Tier 1. 독립 운영 관제 포털 (Standalone Admin Console)
경로: /admin (admin.html, admin.css)
- 사내 다중 시스템(App ID)별 가이드 중앙 제어, KPI 모니터링, 가이드 마스터 테이블, 스텝 상세 조회, 1-Click 임베드 발급 및 북마클릿 제공.
▼ REST API (/api/admin/stats, /api/tours)
⚡ Tier 2. 백엔드 엔진 & 경량 임베디드 DB (Engine Server)
엔진: Node.js (v24), Express 4.19, SQLite Native Database (data/dap.db)
- 시스템/URL 복합 인덱스(1ms 내 응답), ACID 트랜잭션 동시성 보장, Express/HTTP 듀얼 폴백 서빙.
▼ 1줄 SDK 임베드 (<script src=".../runtime.js" data-app-id="...">)
🎯 Tier 3. 클라이언트 임베드 런타임
파일: runtime.js, runtime.css, Driver.js v1.3
- 팝오버 투명도 슬라이더(20%~100%), [👁️ 비침] 투시 버튼, What's New 1회 자동 팝업, 모바일 터치 최적화 헬프 버튼.
🛠️ Tier 4. 현장 저작 도구 (Authoring Studio)
파일: builder.js, builder.css, Live Bookmarklet
- 실제 ERP/포털 화면 요소를 직접 클릭하여 인터랙티브 가이드를 만들고 백엔드로 전송하는 제로코드 저작기.
완전 독립 실행 (Zero-Dependency) 안전성

외부 CDN이나 클라우드 연결 없이 사내 폐쇄망(Intranet)에서도 100% 자체 구동됩니다.

초고속 인덱싱 (Sub-millisecond) 성능

수만 개의 가이드가 등록되어도 사용자가 현재 머무는 URL의 가이드만 1ms 내로 핀포인트 다운로드합니다.

다중 업무 시스템 통합 (Multi-App) 확장성

ERP, 그룹웨어, 고객 CRM 등 서로 다른 도메인과 시스템을 하나의 DAP 허브에서 통합 관리합니다.

2. 프론트엔드 및 런타임 기술 (Frontend & In-App Runtime)

화면 오염 없는 네이티브 자바스크립트 엔진과 사용자 친화적인 인터랙티브 UX

Driver.js (v1.3.1 IIFE) Core Engine

웹 화면 요소에 스포트라이트 조명을 비추고 팝오버를 가이드하는 경량 오픈소스 인터랙티브 투어 엔진입니다.

  • SVG Path Masking: 백그라운드 딤 처리 및 선택된 요소 부드러운 하이라이트
  • 반응형 위치 자동 계산: top, bottom, left, right 위치 및 충돌 회피
  • Lifecycle Hook 제어: onPopoverRender, onDestroyed 등을 커스텀 확장하여 투명도 컨트롤러 부착
No-Code In-App Builder (builder.js) Authoring

코딩 지식이 없는 기획자/운영자도 화면 위 요소를 직접 마우스로 클릭하여 가이드를 작성하는 현장 저작기입니다.

  • 스마트 셀렉터 생성기: 고유 ID, 고유 클래스, 계층 경로를 분석하여 안정적인 CSS 셀렉터 자동 추론
  • 플로팅 드래그 툴바: 작업 중 화면을 가리지 않도록 마우스 드래그로 자유롭게 이동 가능
  • 실시간 단계 편집 및 순서 변경: 추가, 삭제, 위치 변경 후 원클릭 배포
DAP Runtime Player (runtime.js) User Experience

대상 웹앱에 삽입되어 가이드를 다운로드하고 팝오버를 제어하는 엔드유저용 실행 엔진입니다.

  • 풍선 도움말 실시간 투명도 슬라이더: 20%~100% 미세 조절 및 로컬 스토리지 상태 기억
  • [👁️ 비침] 퀵 투시 버튼: 도움말에 가려진 아래 화면 데이터를 누르는 동안 즉시 투시
  • What's New 1회 자동 팝업: 신규 배포 시 세련된 카드 모달 자동 노출 후 둘러보기 연계
  • 모바일 뷰포트 최적화: 48px 컴팩트 터치 버튼, 92vw 반응형 팝오버 지원
독립 관리 콘솔 (admin.html, admin.css) Zero-CDN SPA

외부 네트워크 통신이 전혀 없는 100% 독립형 관리자 포털 대시보드입니다.

  • Zero-Error 인라인 SVG 파비콘: 404 없이 번개 아이콘 즉시 렌더링
  • 엔터프라이즈 CSS 변수 시스템: 산세리프 시스템 폰트, 커스텀 스크롤바, 카드 섀도우
  • 스텝 인스펙터 (Step Inspector): 각 가이드의 스텝별 셀렉터와 팝오버 속성을 카드 형태로 정밀 검사
⚙️

3. 백엔드 및 서버 프레임워크 (Backend & Server Engine)

Node.js 기반 고성능 비동기 I/O 및 이중화 Fallback 서버 아키텍처

Node.js 런타임 (v24.x LTS 호환) Runtime

비동기 이벤트 기반 논블로킹 I/O 모델로 수많은 사용자의 가이드 조회 요청을 단일 스레드로 효율적으로 처리합니다.

  • 최신 V8 JavaScript 엔진 기반 초고속 파싱
  • 기본 내장 모듈 (path, fs, http, url) 활용 극대화
Express.js (v4.19.2) REST Framework

엔터프라이즈 RESTful API 엔드포인트와 정적 파일 호스팅을 담당하는 웹 프레임워크입니다.

  • CORS 완전 개방: cors() 미들웨어를 통해 포트가 다른 사내 업무 시스템에서도 자유롭게 스크립트 호출 허용
  • URL & 시스템 필터링 라우팅: GET /api/tours?url=...&appId=...
  • 정적 자산 고속 서빙: runtime.js, builder.js, admin.html 즉시 전달

🛡️ 무중단 듀얼 서버 아키텍처 (Dual Fallback Serving)

server.js는 try { const express = require('express'); ... } catch (e) { ... } 구조로 설계되어 있습니다. 신규 서버 배포 시 node_modules가 아직 설치되지 않았거나 Express 로딩에 실패하더라도, Node.js 기본 내장 http.createServer를 통해 100% 동일한 기능의 REST API 및 정적 서빙으로 즉시 자동 전환(Fallback)되어 서비스 중단을 원천 차단합니다.

4. 데이터베이스 및 스토리지 (Database & Persistence Engine)

ACID 트랜잭션, 복합 인덱스, 파일 기반 내장형 SQLite 3

Native node:sqlite (DatabaseSync) Primary Driver

Node.js 22.5.0 이상에 기본 내장된 공식 C++ 네이티브 SQLite 바인딩 엔진입니다.

  • 외부 바이너리 컴파일(Python/C++ 도구) 없이 노드 자체 엔진만으로 완전 네이티브 SQLite 구동
  • 동기식 API(DatabaseSync)로 웹 요청 간 락 없는 순차 트랜잭션 보장
  • Node.js 구버전 환경을 위해 better-sqlite3 드라이버 자동 감지 폴백 레이어 탑재
초고속 복합 색인 (Composite Index) Performance

시스템 규모가 확장되어 수백 개 시스템의 수만 개 URL이 등록되어도 지연 없는 인덱싱을 제공합니다.

  • 복합 인덱스: CREATE INDEX idx_tours_app_url ON tours (app_id, target_url);
  • 타입 인덱스: CREATE INDEX idx_tours_type ON tours (type);
  • 데이터 영속성: data/dap.db 단일 파일로 손쉬운 원클릭 백업 및 이관 지원
-- nocodedapEx 데이터베이스 DDL 구조 CREATE TABLE IF NOT EXISTS tours ( id TEXT PRIMARY KEY, -- 투어 고유 식별자 app_id TEXT NOT NULL DEFAULT 'default', -- 대상 시스템 (예: erp, portal, crm) target_url TEXT NOT NULL DEFAULT '/', -- 노출 대상 페이지 경로 (예: /orders) title TEXT NOT NULL, -- 가이드 제목 description TEXT, -- 가이드 상세 설명 type TEXT DEFAULT 'general', -- onboarding, whats-new, page-guide version TEXT DEFAULT '1.0.0', -- 가이드 버전 auto_launch_once INTEGER DEFAULT 0, -- 첫 접속 시 1회 자동 팝업 플래그 steps_json TEXT NOT NULL, -- 직렬화된 가이드 단계 배열 created_at TEXT, updated_at TEXT );

5. 임베드 및 현장 저작 연동 기술 (Integration Architecture)

글로벌 상용 DAP(WalkMe, Pendo)와 동일한 2가지 연동 패러다임

1. 단 1줄 클라이언트 런타임 SDK

안내를 띄우고자 하는 사내 웹사이트의 <head> 또는 <body>에 아래 스크립트를 삽입하면 모든 설정이 완료됩니다.

<script src="http://localhost:3050/runtime.js" data-app-id="enterprise-erp" defer> </script>

2. 외부 웹사이트 현장 저작 북마클릿 (Live Bookmarklet)

브라우저 북마크에 등록해 두고, 가이드를 만들고 싶은 실제 ERP/웹화면에서 클릭하면 화면 위에 현장 저작기가 즉시 주입됩니다.

javascript:(function(){ window.DAP_SERVER_URL = 'http://localhost:3050'; const s = document.createElement('script'); s.src = 'http://localhost:3050/builder.js'; document.body.appendChild(s); })();
