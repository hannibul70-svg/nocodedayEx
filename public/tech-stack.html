1. 시스템 전체 아키텍처 (4-Tier Standalone Architecture)

외부 클라우드나 무거운 RDBMS 서버 없이 100% 로컬 및 사내 인트라넷에서 자립 구동되는 4계층 분리 구조

👑 Tier 1. 독립 운영 관제 포털 (Vanilla JS SPA Admin Console)
경로: http://localhost:3050/admin (admin.html, admin.css)
- Vanilla JS SPA (바닐라 자바스크립트 기반 무프레임워크 SPA): React, Vue 등 무거운 외부 프레임워크 종속 없이 순수 브라우저 표준 기술로 구현된 초경량 단일 페이지 애플리케이션.
- Zero-CDN 순수 로컬 스타일링: 사내 폐쇄망 100% 호환, 외부 의존성 없음, 번개 SVG 파비콘 (Zero 404)
- 주요 관제 기능: 연동 시스템(App ID)별 가이드 중앙 제어, KPI 모니터링, 가이드 마스터 테이블, 스텝 상세 조회, 1-Click 임베드 발급 및 북마클릿 제공.
▼ RESTful API 통신 (/api/admin/stats, /api/tours, /api/guides)
⚡ Tier 2. 백엔드 고속 인덱싱 엔진 (Backend & Storage)
런타임: Node.js (v24.x LTS 호환), Express 4.19 + Node.js 네이티브 HTTP 듀얼 Fallback 서버
스토리지: SQLite3 파일 기반 RDBMS (data/dap.db) - Node 22.5+ 내장 node:sqlite C++ 네이티브 바인딩
- 시스템/URL 복합 인덱스(idx_tours_app_url)로 수만 개 가이드 중 현재 URL 가이드만 1ms 내 초고속 핀포인트 쿼리
- ACID 트랜잭션 동시성 보장 및 tours.json 부팅 시 무손실 자동 마이그레이션.
▼ 1줄 SDK 임베드 (<script src=".../runtime.js" data-app-id="..." defer>) / 실시간 현장 주입
🎯 Tier 3. 클라이언트 임베드 런타임 (Runtime Engine)
파일: runtime.js, runtime.css, Driver.js v1.3.1
- 풍선 도움말 투명도 슬라이더: 20%~100% 실시간 조절 및 LocalStorage 기억
- [👁️ 비침] 원클릭 퀵 투시 버튼: 가려진 화면 데이터를 누르는 동안 0.15로 투시
- What's New 1회 자동 팝업: 신규 배포 시 모달 안내 후 둘러보기 연계
- 모바일 터치 최적화: 48px 원형 플로팅 헬프 버튼, 92vw 반응형 팝오버.
🛠️ Tier 4. 현장 노코드 저작 도구 (Authoring Studio)
파일: builder.js, builder.css, Live Bookmarklet
- 스마트 CSS 셀렉터 자동 추론 엔진: 요소 클릭 시 안정적인 고유 경로 자동 추출
- 플로팅 드래그 저작 툴바: 작업 중 자유로운 위치 이동
- 현장 저작 북마클릿: 외부 ERP/포털 어디서나 브라우저 북마크 클릭으로 저작기 즉시 주입.
완전 독립 실행 (Zero-Dependency) 안전성

외부 CDN이나 외부 클라우드 연결 없이 사내 폐쇄망(Intranet)에서도 100% 자체 구동됩니다.

초고속 인덱싱 (Sub-millisecond) 성능

수만 개의 가이드가 등록되어도 사용자가 현재 머무는 URL의 가이드만 1ms 내로 핀포인트 다운로드합니다.

다중 업무 시스템 통합 (Multi-App) 확장성

ERP, 그룹웨어, 고객 CRM 등 서로 다른 도메인과 시스템을 하나의 DAP 허브에서 통합 관리합니다.

2. 프론트엔드 및 런타임 기술 (Frontend & In-App Runtime)

화면 오염 없는 네이티브 자바스크립트 엔진과 사용자 친화적인 인터랙티브 UX

Vanilla JS SPA Architecture Zero-Framework SPA

React, Vue, Angular, Svelte, Webpack, Vite 등 일체의 외부 프레임워크나 복잡한 빌드 도구 없이, 순수 브라우저 표준 Vanilla JavaScript (ES6+)만으로 상태 관리, 비동기 통신, 라우팅, 컴포넌트 렌더링을 구현한 초경량 단일 페이지 애플리케이션(SPA) 아키텍처입니다.

  • Zero-Build & Zero-Transpile: 별도 컴파일/번들링 과정이 없어 저장 즉시 브라우저에서 0초 실행
  • 네이티브 브라우저 API 풀 활용: Fetch API, async/await, DOM API, Event Delegation, CustomEvent, localStorage
  • 초경량 번들 & 공급망 보안 취약점 제로: 수 MB에 달하는 라이브러리 번들 오버헤드가 전혀 없고 외부 의존성 해킹 위험 원천 차단
  • 단일 인메모리 상태 머신: state = { tours, stats, selectedApp, searchQuery, origin } 중앙 객체를 통한 단방향 데이터 흐름 및 반응형 렌더링
Driver.js (v1.3.1 IIFE) Core Engine

웹 화면 요소에 스포트라이트 조명을 비추고 팝오버를 가이드하는 경량 오픈소스 인터랙티브 투어 엔진입니다.

  • SVG Path Masking: 백그라운드 딤 처리 및 선택된 요소 부드러운 하이라이트
  • 반응형 위치 자동 계산: top, bottom, left, right 위치 및 충돌 회피
  • 안전한 Lifecycle Hook: onPopoverRender, onDestroyed 공식 훅 연동 (재귀 버그 방지)
DAP Runtime Player (runtime.js) End-User UX

대상 웹앱에 삽입되어 가이드를 다운로드하고 팝오버를 제어하는 엔드유저용 실행 엔진입니다.

  • 풍선 도움말 투명도 슬라이더: 20%~100% 범위 실시간 조절 및 LocalStorage(tour_popover_opacity) 상태 기억
  • [👁️ 비침] 퀵 투시 버튼: 마우스/터치 유지 시 0.15 투명도로 즉시 투시, 뗄 때 복귀
  • What's New 1회 자동 팝업: 신규 배포 시 autoLaunchOnce: true 및 dap_seen_* 검사 후 자동 노출
  • 모바일 터치 최적화: 48px 컴팩트 터치 버튼, 92vw 반응형 팝오버, 세로 스택 액션 버튼
  • 가이드 기록 초기화: DapRuntime.resetHistory()로 첫 방문 상태 즉시 복원
No-Code In-App Builder (builder.js) Authoring Studio

코딩 지식이 없는 기획자/운영자도 화면 위 요소를 직접 마우스로 클릭하여 가이드를 작성하는 현장 저작기입니다.

  • 스마트 셀렉터 생성기: 고유 ID, 고유 클래스, 계층 경로를 분석하여 안정적인 CSS 셀렉터 자동 추론
  • 플로팅 드래그 툴바: 작업 중 화면을 가리지 않도록 마우스 드래그로 자유롭게 이동 가능
  • 실시간 단계 편집 및 순서 변경: 추가, 삭제, 위치 변경 후 원클릭 배포
  • 이벤트 캡처링 방지: 빌더 조작 중 대상 사이트의 본래 클릭 이벤트 차단
독립 관리 콘솔 (admin.html, admin.css) Zero-CDN SPA

외부 네트워크 통신이 전혀 없는 100% 독립형 관리자 포털 대시보드입니다.

  • Zero-Error 인라인 SVG 파비콘: 404 없이 번개 아이콘 즉시 렌더링
  • 엔터프라이즈 CSS 변수 시스템: 산세리프 시스템 폰트, 커스텀 스크롤바, 카드 섀도우
  • 스텝 인스펙터 (Step Inspector): 각 가이드의 스텝별 셀렉터와 팝오버 속성을 카드 형태로 정밀 검사
  • 1-Click 임베드 & 북마클릿 발급기: 사내 업무 시스템별 1줄 코드 즉시 생성
⚙️

3. 백엔드 및 서버 프레임워크 (Backend & Dual Fallback Engine)

Node.js 기반 고성능 비동기 I/O 및 이중화 Fallback 서버 아키텍처

Node.js 런타임 (v24.x LTS 호환) Runtime

비동기 이벤트 기반 논블로킹 I/O 모델로 수많은 사용자의 가이드 조회 요청을 단일 스레드로 효율적으로 처리합니다.

  • 최신 V8 JavaScript 엔진 기반 초고속 파싱
  • 기본 내장 모듈 (path, fs, http, url) 활용 극대화
Express.js (v4.19.2) REST Framework

엔터프라이즈 RESTful API 엔드포인트와 정적 파일 호스팅을 담당하는 웹 프레임워크입니다.

  • CORS 완전 개방: cors() 미들웨어를 통해 포트가 다른 사내 업무 시스템에서도 자유롭게 스크립트 호출 허용
  • 정적 자산 고속 서빙: runtime.js, builder.js, admin.html 즉시 전달
  • 입력 유효성 검사: validateTourInput으로 스텝 셀렉터 및 타이틀 누락 사전 차단

🛡️ 무중단 듀얼 서버 아키텍처 (Dual Fallback Serving)

server.js는 try { const express = require('express'); ... } catch (e) { ... } 구조로 설계되어 있습니다. 신규 서버 배포 시 node_modules가 아직 설치되지 않았거나 Express 로딩에 실패하더라도, Node.js 기본 내장 http.createServer를 통해 100% 동일한 기능의 REST API 및 정적 서빙으로 즉시 자동 전환(Fallback)되어 서비스 중단을 원천 차단합니다.

4. 전체 REST API 규격서 (Complete API Specifications)

클라이언트 런타임, 저작 빌더, 독립 운영 관제 포털이 사용하는 표준 HTTP 인터페이스

HTTP 메서드 엔드포인트 경로 파라미터 / 페이로드 설명 및 주요 역할
GET /api/tours ?url=:pathname&appId=:id 특정 URL 및 시스템(App ID)에 매칭되는 가이드 목록 조회 (1ms 핀포인트 쿼리)
GET /api/guides ?url=:pathname&appId=:id /api/tours 엔드포인트의 별칭(Alias) 라우트 (하위 호환성 100% 보장)
POST /api/tours JSON Body (title, target_url, app_id, steps, ...) 신규 가이드 등록 또는 기존 가이드 업데이트 (ACID 원자적 트랜잭션 저장)
DELETE /api/tours/:id Path: :id (투어 식별자) 특정 가이드 투어 삭제 (성공 시 200, 없을 시 404 반환)
GET /api/admin/stats 없음 관리자 포털용 통계 지표 (연동 앱 목록, 앱별 투어 수, 총 투어 수, 총 스텝 수)
GET /admin 없음 독립 운영 관리 포털 SPA 메인 웹페이지 (public/admin.html 서빙)
GET / 또는 /index.html 없음 DAP Enterprise 샘플 대시보드 포털 서빙 (반응형 테스트용 웹페이지)

5. 데이터베이스 및 스토리지 (Database & Persistence Engine)

ACID 트랜잭션, 복합 인덱스, 파일 기반 내장형 SQLite 3

Native node:sqlite (DatabaseSync) Primary Driver

Node.js 22.5.0 이상에 기본 내장된 공식 C++ 네이티브 SQLite 바인딩 엔진입니다.

  • 외부 바이너리 컴파일(Python/C++ 도구) 없이 노드 자체 엔진만으로 완전 네이티브 SQLite 구동
  • 동기식 API(DatabaseSync)로 웹 요청 간 락 없는 순차 트랜잭션 보장
  • Node.js 구버전 환경을 위해 better-sqlite3 드라이버 자동 감지 폴백 레이어 탑재
초고속 복합 색인 (Composite Index) Performance

시스템 규모가 확장되어 수백 개 시스템의 수만 개 URL이 등록되어도 지연 없는 인덱싱을 제공합니다.

  • 복합 인덱스: CREATE INDEX idx_tours_app_url ON tours (app_id, target_url);
  • 타입 인덱스: CREATE INDEX idx_tours_type ON tours (type);
  • 데이터 영속성: data/dap.db 단일 파일로 손쉬운 원클릭 백업 및 이관 지원
  • 자동 마이그레이션: 부팅 시 기존 tours.json 데이터를 SQLite DB로 무손실 이관
-- nocodedapEx 데이터베이스 DDL 구조 CREATE TABLE IF NOT EXISTS tours ( id TEXT PRIMARY KEY, -- 투어 고유 식별자 app_id TEXT NOT NULL DEFAULT 'default', -- 대상 시스템 (예: erp, portal, crm) target_url TEXT NOT NULL DEFAULT '/', -- 노출 대상 페이지 경로 (예: /orders) title TEXT NOT NULL, -- 가이드 제목 description TEXT, -- 가이드 상세 설명 type TEXT DEFAULT 'general', -- onboarding, whats-new, page-guide version TEXT DEFAULT '1.0.0', -- 가이드 버전 auto_launch_once INTEGER DEFAULT 0, -- 첫 접속 시 1회 자동 팝업 플래그 steps_json TEXT NOT NULL, -- 직렬화된 가이드 단계 배열 created_at TEXT, updated_at TEXT ); CREATE INDEX IF NOT EXISTS idx_tours_app_url ON tours (app_id, target_url);

6. 임베드 및 현장 저작 연동 기술 (Integration Architecture)

글로벌 상용 DAP(WalkMe, Pendo)와 동일한 2가지 연동 패러다임

1. 단 1줄 클라이언트 런타임 SDK

안내를 띄우고자 하는 사내 웹사이트의 <head> 또는 <body>에 아래 스크립트를 삽입하면 모든 설정이 완료됩니다.

<script src="http://localhost:3050/runtime.js" data-app-id="enterprise-erp" defer> </script>

2. 외부 웹사이트 현장 저작 북마클릿 (Live Bookmarklet)

브라우저 북마크에 등록해 두고, 가이드를 만들고 싶은 실제 ERP/웹화면에서 클릭하면 화면 위에 현장 저작기가 즉시 주입됩니다.

javascript:(function(){ window.DAP_SERVER_URL = 'http://localhost:3050'; const s = document.createElement('script'); s.src = 'http://localhost:3050/builder.js'; document.body.appendChild(s); })();

7. 3-Role 오케스트레이션 하네스 & 개발 공정 (SDLC & Engineering)

Google Antigravity Agentic 하네스를 통한 Spec-Driven Development (SDD) 무결점 개발 체계

spec-advisor Pro Tier

코드 수정 절대 금지. 사용자 요구사항을 분석하여 6대 표준 정밀 기술 명세서(Spec & Plan) 작성 및 검증 기준 수립.

worker Flash Tier
